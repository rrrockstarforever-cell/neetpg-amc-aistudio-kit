# NEET PG / AMC Prep: Google AI Studio build kit

Everything needed to have Google AI Studio (Build mode) generate the app.

1. Open AI Studio > Build, paste `AI_STUDIO_PROMPT.md`.
2. Attach/paste `design/clinical_focus/DESIGN.md` (design system) and the `design/*/code.html` + `screen.png` for each screen.
3. `requirements.md` is the functional spec; `gap-audit.md` lists features that are designed but not yet built.
4. `reference-extension/` is the existing working logic (FSRS rating flow, question-bank runner, analytics, Anki TSV export, search/topics model) for behaviour reference only. It is not a runnable app on its own.

No API keys, user data, PDFs or question banks are included.
